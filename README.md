# KawanFreelance 💼✨

**Toolkit Finansial & Administrasi Lengkap untuk Freelancer Indonesia**  
*100% Client-Side • Tanpa Watermark • Privasi Aman • Gratis & Open Source*

🌐 **Live Demo (GitHub Pages)**: [https://fahmiprasanda123.github.io/kawan-freelance/](https://fahmiprasanda123.github.io/kawan-freelance/)

---

## 🚀 Fitur Utama

1. **Generator Invoice Pro**
   - Preview realtime berstandar A4 (Pixel-Perfect).
   - Ekspor PDF tajam dan presisi tanpa terpotong (menggunakan `html2canvas` + `jsPDF`).
   - Perhitungan otomatis Subtotal, Diskon, PPN, dan PPh 23.
   - Konversi otomatis nominal angka ke teks terbilang bahasa Indonesia.
   - Pad tanda tangan digital interaktif langsung di browser.
   - Kotak materai opsional.

2. **Generator Kuitansi Resmi**
   - Format standar bukti tanda terima pembayaran formal landscape A4.
   - Auto-terbilang nominal rupiah.
   - Dukungan tanda tangan digital & stempel materai Rp 10.000.
   - Ekspor PDF resmi 1 klik.

3. **Kalkulator Pajak Freelancer 2024**
   - Skema **PPh 21 TER (Tarif Efektif Rata-rata)** bulanan sesuai aturan terbaru PP 58/2023 & PMK 168/2023.
   - Simulasi **NPPN 50% (Norma Penghitungan Penghasilan Neto)** tahunan untuk pekerja bebas.
   - Rincian PTKP (TK/0 s.d K/3) dan perbandingan beban pajak yang transparan.

4. **100% Client-Side & Privasi Terjaga**
   - Tidak ada data transaksi, rekening, atau nama klien yang dikirim ke server.
   - Semua pemrosesan berlangsung langsung di browser Anda.

## 🛠️ Teknologi

- **Frontend**: Semantic HTML5, Modern CSS (Glassmorphism & Responsive Layout), Vanilla JavaScript (Modular).
- **PDF Engine**: `html2canvas` & `jsPDF` untuk render PDF A4 pixel-perfect.
- **Icons**: Lucide Icons.
- **Typography**: Plus Jakarta Sans & JetBrains Mono.

## 💻 Cara Menjalankan

Tidak memerlukan build step atau database. Cukup buka file:

1. Clone repository ini:
   ```bash
   git clone https://github.com/fahmiprasanda123/kawan-freelance.git
   cd kawan-freelance
   ```
2. Buka `index.html` langsung di browser, atau jalankan menggunakan local server (misal: Live Server / Python HTTP Server):
   ```bash
   python3 -m http.server 8080
   ```
3. Akses di browser pada `http://localhost:8080`.
